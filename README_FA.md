# سایت شخصی Ali Gholizadeh

این نسخه با HTML، CSS و JavaScript ساخته شده و مستقیم روی GitHub Pages اجرا می‌شود. به npm، React، دیتابیس یا سرور بک‌اند نیاز ندارد. فونت‌ها، آیکون‌ها و تصویرهای مورد نیاز همراه پروژه هستند.

## دیدن سایت روی کامپیوتر

ZIP را استخراج کن و فایل `index.html` را در مرورگر باز کن.

برای پیش‌نمایش از طریق localhost، در پوشه‌ای که `index.html` قرار دارد اجرا کن:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کن. بعداً برای متوقف‌کردن سرور، `Ctrl+C` بزن.

## انتشار روی GitHub Pages

1. مخزن `aligholizadeh8413.github.io` را باز کن.
2. **محتویات استخراج‌شدهٔ ZIP** را در ریشهٔ مخزن قرار بده. خود ZIP را آپلود نکن و فایل‌ها را داخل یک پوشهٔ اضافی نگذار؛ `index.html` باید در ریشه باشد.
3. فایل‌های `index.html`، `styles.css`، `script.js`، `config.js`، پوشهٔ `assets` و فایل `.nojekyll` باید در مخزن باشند. در مک فایل آخر مخفی است؛ با `Cmd+Shift+.` می‌توانی آن را ببینی.
4. تغییرات را commit کن.
5. در `Settings → Pages`، گزینهٔ `Deploy from a branch` را انتخاب کن؛ شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کن. اگر شاخهٔ اصلی مخزن نام دیگری دارد، همان شاخهٔ حاوی فایل‌ها را انتخاب کن.
6. پس از پایان انتشار در تب Actions، سایت در `https://aligholizadeh8413.github.io/` نمایش داده می‌شود.

اگر انتشار مخزن از قبل با GitHub Actions تنظیم شده است، تنظیم بالا آن را به انتشار مستقیم فایل‌های شاخه تغییر می‌دهد. برای این پروژه هیچ workflow اختصاصی لازم نیست.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## اضافه‌کردن ویدئوی AioDesk

در فایل‌های دریافتی این نسخه، ویدئو وجود نداشت؛ بنابراین فعلاً تصویر مفهومی نمایش داده می‌شود. برای جایگزینی:

1. در `assets` پوشه‌ای به نام `video` بساز.
2. ویدئو را با نام `aiodesk-motion.mp4` داخل آن قرار بده. MP4 با کدک H.264 انتخاب مناسبی برای مرورگرهاست؛ نسبت 16:10 با تصویر فعلی هماهنگ است، ولی پلیر نسبت‌های دیگر را هم نمایش می‌دهد.
3. در `config.js` مقدار مربوطه را تغییر بده:

```javascript
window.PORTFOLIO_CONFIG = Object.freeze({
  aiodeskVideo: "assets/video/aiodesk-motion.mp4",
  aiodeskCaptions: "",
  cvUrl: "",
  plainResumeUrl: ""
});
```

با این تغییر، ویدئو جای تصویر را می‌گیرد و کنترل‌های پخش مرورگر نمایش داده می‌شوند. پخش خودکار فعال نیست. ویدئو هنگام خارج‌شدن از محدودهٔ دید یا رفتن به تب دیگر متوقف می‌شود. اگر مسیر ویدئو اشتباه باشد، تصویر موقت دوباره نمایش داده می‌شود.

برای ویدئوی دارای گفتار، فایل زیرنویس WebVTT را در `aiodeskCaptions` معرفی کن. زبان فعلی track انگلیسی است و در `script.js` قابل تغییر است.

## فعال‌کردن Download CV و Plain resume

این دو گزینه طبق درخواست فعلاً رزرو شده‌اند و پیام «به‌زودی» دارند. بعد از آماده‌شدن فایل‌ها، فقط مسیرها را در `config.js` قرار بده:

```javascript
cvUrl: "assets/Ali-Gholizadeh-CV.pdf",
plainResumeUrl: "resume.html"
```

فایل PDF و صفحهٔ `resume.html` باید واقعاً در این مسیرها موجود باشند. فایل صفحهٔ رزومه در این نسخه ساخته نشده است. اگر خواستی، مسیر plain resume می‌تواند به فایل PDF دیگری هم اشاره کند.

## فرم تماس دقیقاً چگونه کار می‌کند؟

فرم، نام و ایمیل و متن پیام را اعتبارسنجی می‌کند و **پیش‌نویس ایمیل را در برنامهٔ ایمیل بازدیدکننده باز می‌کند**. بازدیدکننده باید ارسال را در برنامهٔ ایمیل تأیید کند. اطلاعات در سایت ذخیره نمی‌شوند.

اگر روی دستگاه برنامهٔ ایمیل تنظیم نشده باشد، لینک ایمیل و دکمهٔ Copy email همچنان راه‌های جایگزین هستند. برای ارسال مستقیم از داخل صفحه، بعداً باید سرویس فرم یا بک‌اند جدا وصل شود؛ GitHub Pages این کد سمت سرور را اجرا نمی‌کند.

## تغییر محتوا و طراحی

- اطلاعات معرفی و تحصیلات از README ارسالی تهیه شده‌اند؛ جزئیات AioDesk از توضیحاتی که دربارهٔ پروژه داده بودی گرفته شده‌اند.
- اطلاعات شخصی، متن‌ها و لیست مهارت‌ها داخل `index.html` هستند. برای تغییر لینک‌های تماس، موارد متناظر در `index.html` و ایمیل داخل `script.js` را هم به‌روز کن.
- رنگ‌های اصلی در ابتدای `styles.css` و بلوک `:root` قرار دارند.
- ظاهر صفحه همیشه تیره است. بخش‌های خواسته‌شدهٔ About، Projects، Educations و Contacts در ناوبری قرار دارند.
- انیمیشن ورود بخش‌ها ساده و تدریجی است؛ با فعال‌بودن Reduce Motion در سیستم‌عامل، حرکت‌ها غیرفعال می‌شوند.
- چیدمان در عرض‌های کوچک به یک ستون تبدیل می‌شود؛ منوی بالای صفحه هم به منوی موبایل تبدیل می‌شود.
- بدون JavaScript متن‌ها و لینک‌های اصلی قابل مشاهده هستند؛ امکانات تعاملی به JavaScript نیاز دارند.

## بررسی انجام‌شده

پیش‌نمایش در مرورگر دسکتاپ و عرض‌های موبایل ۳۲۰ و ۳۹۰ پیکسل بررسی شده است. باز و بسته‌شدن منوی موبایل، پیمایش به بخش تماس، پنجرهٔ جزئیات پروژه و بستن آن با Escape بررسی شدند. مسیر فایل‌های داخلی و نحو JavaScript نیز بررسی شده‌اند.
