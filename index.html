NOTES FROM A BACKEND JOURNEY

I'm a Computer Science student at Kharazmi University, drawn to the logic behind the interface.

My focus is backend development with Python. I'm learning Django through a hands-on web development course, and putting object-oriented programming, design patterns, and unit testing into practice.

AioDesk is where a lot of that curiosity becomes concrete: devices, APIs, sessions, databases, and background jobs—all parts of one system I can build and understand.

I enjoy solving problems, exploring new technologies, and learning alongside other people. Most days, you'll find me working in Linux or macOS, making the next small thing work a little better.

A PERSONAL LEARNING PROJECT

Inside AioDesk.

An ongoing help desk and device-monitoring project built to turn backend concepts into something tangible.

01 / THE APPLICATION

A place to manage devices.

A FastAPI backend and web dashboard bring device reports, support tickets, and account settings together.

02 / THE CONNECTION

An agent on the other side.

A Python agent registers with the server and sends device reports. Building both sides helps me understand the whole conversation.

03 / THE BACKGROUND WORK

Learning beyond the request.

Redis and RabbitMQ are part of the learning journey: sessions, caching, rate limiting, and queued email delivery.

A personal learning project, actively evolving as I explore the parts of a connected system.
